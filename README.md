# 无头骑士大师 · Knight

**没屏幕的 MacBook，在家让它一直醒着，出门让它真的睡。**

拆了屏、或者合上盖子接着外接屏用的 MacBook，日常就这两件事：让它醒着干活，和让它睡着带走。
这个菜单栏小工具把它们各做成一个开关，顺便告诉你「它到底睡没睡」。

<img src="https://hkm.886366.xyz/assets/shots/home.png" width="300" alt="主界面：在家，一个「开始外出模式」按钮">

## 它解决的是这三个麻烦

1. **明明让它别睡，它还是睡了。** 没屏幕的机器没人碰，系统按自己的空闲时间就睡了。
   本地跑个模型、等个长任务，回来发现早断了。
2. **想让它睡的时候，它不睡。** 界面说已经睡了，键盘灯还亮着。因为有三层东西在拦：
   系统设置、别的程序、蓝牙和网络唤醒。
3. **出门一趟，不知道它睡没睡。** 回来一看电量掉了一截，也不知道被谁叫醒的。

## 在家：让它醒着

- **断开内建屏。** 勾一下，那块屏从系统里摘掉。省电，而且外接屏终于能按你要的方向摆——
  内屏在线的时候，macOS 会把外接屏转回横的。
- **不让它自己睡。** 没人动它也不睡。但你想让它睡的时候照样能睡，两件事不冲突。
- **⌘H** 随时接回 / 断开内建屏。

## 出门：点一下，然后拔线

1. 点菜单栏图标，点「开始外出模式」。
2. 它列出正在挡睡眠的程序。你确认一下要不要关——**不点它不会动手**，怕丢你没保存的东西。
3. 看到「可以拔掉显示器了」，拔线。
4. 几秒后键盘灯灭，就能装包走了。半路被碰醒，它会自己再睡回去。

回来插上线，点「结束外出模式」：设置自动还原，再给你一份报告——睡了多久、醒过几次、
几点、为什么、掉了多少电。

## 它不会做什么

- **拦不住你按键盘。** 包里压到键、触控板被顶住，机器就会被叫醒，任何软件都拦不住。
  要么物理挡住，要么靠「增强模式」把它按回去。
- **不会自己关你的程序。** 怕丢未保存的东西，必须你点。
- **关掉蓝牙，「查找」就找不到它了。** 你自己权衡。
- **关掉共享服务，局域网就连不上它。**
- **定时唤醒只取消，不恢复。** 回来要你自己重设。

## 装之前

- 第一次打开要右键 →「打开」。没做公证，系统会拦一次，之后不再拦。
- 改名或移动 App 之后，蓝牙要重新授权（权限按路径记）。
- 界面有中文和英文两套，跟着系统语言走。

## 安装

从 [Releases](../../releases) 下载 `Knight.dmg`，把 `Knight.app` 拖进「应用程序」。

首次启动要授权三样：通知、蓝牙、一个 root 后台服务（写电源设置用）。

## 它怎么做到的

<details>
<summary>点开看：每一步到底改了什么</summary>

| 动作 | 手段 |
|---|---|
| 锁定睡眠 | `disablesleep=0` `sleep=1` `womp=0` `powernap=0` `tcpkeepalive=0` |
| 关闭共享服务 | 只关正在监听的 SMB / 屏幕共享 / AFP，端口没在听就不碰 |
| 关闭蓝牙 | 蓝牙断电，不然外设能把机器叫醒 |
| 暂停 Time Machine | `tmutil disable`，备份一起来就是几十分钟不睡 |
| 退出挡睡眠的程序 | `terminate` → `forceTerminate`，只退真的挡睡眠的 |
| 断开内建屏 | SkyLight `CGSConfigureDisplayEnabled`，勾上就摘掉，唤醒后维持 |
| 防止空闲睡眠 | `PreventUserIdleSystemSleep` 断言，出门自动放开、回来接上 |

**它怎么知道线拔了**：认的是「出门前记下的那块屏还在不在」，不是数屏幕数量。
拔线之后系统常常留一块幽灵屏，数量一直是 1，数数量会永远等不到。

**回来之后**：按出门前的快照还原，再从 `pmset -g log` 里读这一趟睡了多久、
被什么唤醒、掉了多少电。

**增强模式**（默认开）：没结束外出、机器又连续醒着满 5 分钟，就发通知、倒计时 30 秒、
再让它睡一次。只在外接屏已拔掉时生效。

**接不回内建屏的时候**（App 崩了、设置丢了），命令行还有一条路：

```bash
/Applications/Knight.app/Contents/MacOS/Knight --restore-builtin
```

</details>

## 给改代码的人

<details>
<summary>目录、构建、测试</summary>

```
Sources/HKMKit/                核心逻辑：pmset、断言、显示器、唤醒日志、蓝牙、共享服务，不依赖 UI
Sources/HeadlessKnightMaster/  菜单栏 App（SwiftUI + AppKit）
Sources/hkm-helper/            root 提权小工具，只做 pmset 那几件事
Tests/                         294 条测试，含假时钟与假系统
docs/design.md                 设计文档：为什么这么设计、踩过哪些坑
preview/ui.html                界面设计稿
```

macOS 13+，Xcode 15 命令行工具即可。

```bash
./scripts/swift.sh build     # 编译
./scripts/swift.sh test      # 294 条测试
./scripts/build-app.sh       # build/Knight.app
./scripts/make-dmg.sh        # build/Knight.dmg
```

实现上的坑（`pmset sleepnow` 的假成功、自启动不能 bootstrap、共享服务看端口、
只挡屏幕的断言不碰、helper 版本用握手判断）都记在 `docs/design.md` 最后一节。

</details>
